Falade Solomon Adeyemi: personal website

Open index.html to start. Keep this whole folder together.

  index.html          Home
  pages/
    about.html        About
    education.html    Education
    books.html        Books
    research.html     Research and writing
    ministry.html     Christian ministry
    ventures.html     Career and ventures
    connect.html      Email and social media
  css/styles.css      colours, fonts and layout
  js/site.js          the menu, footer, theme switch and copy-email button (used by every page)

Every page has the same menu, so you can move between all the pages.
To add a page: copy one from pages/, change its text, and add it to the NAV list in js/site.js.
The homepage portrait is stored as project.jpeg in the site folder.
